# CIRCArt Preview

CIRCArt is "Hitster for art": place famous artworks on a timeline. This repo is where the online version is developed and tested, with its own test database. The real game is at https://circart.langschwerts.de.

- Preview site: https://nambatu.github.io/circart-preview/ (see `docs/changes.html` for what's new)
- Source: `src/` · Plan and decisions: `notes/` · Instructions for Claude: `CLAUDE.md`
- `docs/`, `supabase/`, `pack-art/`, `card_keys.json` and `pack_images.json` are build output from `src/tools/deploy_preview.sh`.
