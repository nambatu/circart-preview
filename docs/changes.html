PREVIEW · Wed 11 Nov, 17:30

What's new

  • Daily and Monthly Run now give you 45 seconds per card (was 20). In the daily, the 45 seconds cover placing the card and the artist and style questions together.
  • The texts that mention the time are updated in English and German. Games already running keep their old timer.

What to test

  1. Start the Monthly Run: the countdown bar should last about 45 seconds per card.
  2. Open the daily: place a card, then answer the questions; the countdown keeps running from the card start, not from placing.

Something wrong? In the app: Profile → Send feedback, or the flag during a game. It lands in the preview database and the next evening build reads it.

This is a test version with its own database. Your real game at circart.langschwerts.de is not affected.
