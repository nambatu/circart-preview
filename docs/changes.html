PREVIEW · Fri 6 Nov, 08:00

What's new

  • Calmer home screen: "Today" first, then your games, then three cards that all look the same (Solo, Monthly Run, With friends)
  • The code field shows "ABCD" as an example now
  • Card packs moved to the Gallery: Gallery → Packs. Tap a pack to see its paintings (locked ones stay blurred)
  • Two new packs: "Impressionists" (play 5 daily challenges) and "Renaissance Masters" (play 5 solo games)
  • Back button / swipe back: no more lost games. In a game it asks first, and on the home screen a second swipe closes the app
  • German titles and descriptions for the monthly themes
  • Safety: push notifications only go out from our own server job, and a stricter browser security rule is in place
  • Privacy: feedback is no longer copied into the public preview repo

What to test

  1. Open the home screen. Does it feel calmer? Is anything missing?
  2. Gallery → Packs → tap a pack, then use your back swipe (it should close the pack, not the app)
  3. In a solo game, swipe back: it should ask "Leave this game?"
  4. Profile → Language → Deutsch: check the Monthly Run card title
  5. Profile → Send me a test notification (checks the new push protection)

Something wrong? In the app: Profile → Send feedback, or the flag during a game. It lands in the preview database and the next evening build reads it.

This is a test version with its own database. Your real game at circart.langschwerts.de is not affected.
