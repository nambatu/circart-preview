PREVIEW · Thu 26 Nov, 15:00

What's new

  • After your first finished daily, CIRCArt asks once if it may send you one daily reminder, and you pick the time (7, 9, 13, 18 or 20 o'clock). It only comes if you haven't played the daily yet. 'Not now' asks again in a week, 'Never ask me again' stops it.
  • When you start a game with friends that runs over several days, the app asks you to allow notifications.
  • Profile → Notifications is now a small panel: your turn, invites and challenges, and the daily reminder time can each be switched on or off. The test notification is gone.
  • Smaller fixes from the code review: a declined friend request can only be sent again after a week, score challenges always use your real best score, and 'Download my data' now includes reactions and calls.

What to test

  1. Play the daily, pick a time in the pop-up and wait for the reminder tomorrow at that hour.
  2. Profile → Notifications: switch things on and off.
  3. Start a game with friends over several days and check that you're asked about notifications.

Something wrong? In the app: Profile → Send feedback, or the flag during a game. It lands in the preview database and the next evening build reads it.

This is a test version with its own database. Your live game is not affected.
