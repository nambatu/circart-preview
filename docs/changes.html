PREVIEW · Fri 6 Nov, 11:00

What's new

  • Games with friends: new "Timer" switch in the lobby. It is on by default for live games and off for games over a few days
  • Artist and style questions: you see the right answer in green and your wrong pick in red again, even when the bonus time ran out
  • One tap per question. After your first pick the other names are locked
  • The painting stays visible next to the questions (tap it to zoom). With the timer on, you also see the bonus countdown
  • Notifications: Firefox can now ask for permission (please test)
  • Fix: Gallery → Packs now shows your packs (a file was missing from the preview build)
  • One name instead of two: Profile has a single "Your name" field. It is your name in games and on the leaderboards
  • Starting a game no longer asks for your name when you already have one
  • Profile → "Install the app": installs right away in Chrome, or shows how to do it in Firefox and on iPhone
  • The install banner no longer hides behind the tab bar
  • New tutorial texts: shorter, plainer, no maths about points

What to test

  1. Start a game over a few days. The timer is off, so take your time with the artist question and check the green and red answers
  2. Switch the timer on in the lobby and check the countdown on the question screen
  3. In Firefox: Profile → turn on notifications
  4. Tap the painting on the question screen to zoom in

Something wrong? In the app: Profile → Send feedback, or the flag during a game. It lands in the preview database and the next evening build reads it.

This is a test version with its own database. Your real game at circart.langschwerts.de is not affected.
