PREVIEW · Mon 9 Nov, 11:30

What's new

  • Tap any painting to see it big. Pinch or double-tap to zoom in, and tap once to close.
  • "Play this pack" now opens the game on its own full screen.
  • Behind the scenes: the code now lives in this repo, so future updates come out faster.

What to test

  1. Gallery → Packs → open an unlocked pack → "Play this pack": the game should fill the whole screen.
  2. In a game with friends or the daily, tap the painting: it opens big, pinch to zoom, one tap closes it.
  3. Swipe back while a painting is open: it should close the painting, not the game.

Something wrong? In the app: Profile → Send feedback, or the flag during a game. It lands in the preview database and the next evening build reads it.

This is a test version with its own database. Your real game at circart.langschwerts.de is not affected.
