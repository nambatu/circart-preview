PREVIEW · Thu 26 Nov, 19:00

What's new

  • Games with friends over several days start right away. You tap 'Start now' and play turn 1 without waiting. Friends join with the code, the link or an invite while turn 1 is open, and they play the same cards. If nobody joins within a day, the game ends and you get a notification.

What to test

  1. Start a game over several days alone, play turn 1, then let a friend join with the code.
  2. Invite a friend from the friends list: the game starts for you at once, and your friend joins when accepting.

Something wrong? In the app: Profile → Send feedback, or the flag during a game. It lands in the preview database and the next evening build reads it.

This is a test version with its own database. Your live game is not affected.
